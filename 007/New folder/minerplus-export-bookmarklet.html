📥 MinerPlus Export Bookmarklet

One-click export from MinerPlus dashboard

How to Use:

  1. Go to MinerPlus realtime alarm page
  2. Open Browser DevTools Console (F12 → Console tab)
  3. Copy & paste the code below
  4. Press Enter → Pop-up will appear
  5. Select strategy codes and format
  6. Click Export → File downloads automatically!

📋 Copy this code:
